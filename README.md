# Pulse releases

This repository hosts the public macOS update feed and release binaries for Pulse.

The application source is [zhigang1992/Pulse](https://github.com/zhigang1992/Pulse). Sparkle reads [`appcast.xml`](appcast.xml) to discover and verify updates. Every update archive carries an EdDSA signature. Releases after the legacy 0.4.3 seed use Apple Developer ID signing and notarization.

Download releases from the [Releases page](https://github.com/zhigang1992/pulse-releases/releases).
